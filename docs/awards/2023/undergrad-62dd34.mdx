本研究では、YouTubeという動画共有サービスの動画をコメントの内容を基に検索できるシステムの作成を目的としている。扱うチャンネルは3つであり「エンタメ」「音楽」「勉強」とジャンルが異なる。YouTube Data API v3を使用してYouTubeから取得した情報を基に、検索ワードを含むコメントを動画毎にカウントし、その値が最大の動画を検索結果とする。検索ワードが複数の場合は調和平均を用いる。本システムでは動画検索に加え、検索結果の動画の視聴、チャンネル名やヒットしたコメント数等の表示、検索対象となるコメントの追加ができる。評価の結果、感想に書かれやすいワードや感情を表すワードで検索した際に視聴者側に寄り添った検索結果が得られた。
