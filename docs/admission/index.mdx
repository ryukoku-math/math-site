教育職員免許法に基づき、履修要項に定める所定の単位の修得によって、先端理工学部 数理・情報科学課程では

- 中学校教諭 一種免許状 [数学]
- 高等学校教諭 一種免許状 [数学]
- 高等学校教諭 一種免許状 [情報]

が、先端理工学研究科では、対応する一種免許状取得者は

- 中学校教諭 専修免許状 [数学]
- 高等学校教諭 専修免許状 [数学]

が取得できます。詳しくは[教職センターwebサイト](https://www.ryukoku.ac.jp/faculty/kyoshoku/)をご覧ください。
