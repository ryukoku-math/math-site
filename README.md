# math-site

龍谷大学 先端理工学部 数理・情報科学課程の公式サイト
**[www.math.ryukoku.ac.jp](https://www.math.ryukoku.ac.jp)** のソースリポジトリです。

Markdownベースのドキュメントフレームワーク [Blume](https://useblume.dev)（Astro/Vite製）で構築されて
います。このリポジトリにはコンテンツ・設定・少数の手書きAstroページ/コンポーネントのみが含まれ、
フレームワーク自体のコードは含まれません。

## ページを編集する

編集方法は2つあります。どちらの場合も、変更は Pull Request として提案され、管理者の承認後にサイトへ
反映されます（公開サイトへの反映は毎日午前3時の自動デプロイ時です）。

### ニュース記事を投稿・編集する — News Editor

**<https://mathryukoku.pages.dev/admin/news>**

ブラウザのフォームからニュース記事を投稿・編集できるツールです。Markdownやファイル構成を知らなくても
記事を追加できます。

- タイトル・日付・概要・本文を入力し、カバー画像（必須）と本文用の画像をアップロードするだけで投稿できます
- 画像は自動的にJPEGへ変換・縮小されます（iPhoneのHEIC形式の写真もそのまま選べます）
- 投稿すると Pull Request が作られ、**プレビューURLで公開前の見た目を確認**できます
- 内容に問題があれば、その画面から **「修正する」**（同じPRを上書き）または
  **「この投稿を取り消す」**（PRを取り消して破棄）を選べます
- 既存のニュース記事の修正もこの画面から行えます

利用にはGitHubアカウントでのログインが必要です。このリポジトリへの書き込み権限（コラボレーター登録）が
必要なため、初めて使う場合は管理者にご相談ください。

### その他のページを編集する — GitHubのWeb画面

ニュース以外のページ（課程紹介、教員紹介など）は `docs/` 以下の `.mdx` ファイルを直接編集します。
パソコンに開発環境がなくても、GitHubのWeb画面だけで編集できます。

手順は **[CONTRIBUTING.md](CONTRIBUTING.md)** にまとめています（ブランチ作成 → 編集 →
Pull Request → プレビュー確認）。

## ローカル開発

```bash
npm install      # 依存関係をインストール
npm run dev      # 開発サーバー起動（ホットリロード付き、http://localhost:4321）
npm run build    # dist/ に静的出力をビルド
npm run doctor   # 設定・コンテンツの問題を診断
```

Lintやテストスイートはありません（コンテンツのみのプロジェクトのため）。変更内容は `npm run dev` で
実際のページを確認して検証してください。

サイトの配信構成やNews Editorの動作に必要な環境変数は `.env.example` を参照してください（管理者向け）。
