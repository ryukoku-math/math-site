# math-site

龍谷大学先端理工学部数理・情報科学課程の公式サイト
[www.math.ryukoku.ac.jp](https://www.math.ryukoku.ac.jp)のソースリポジトリです。

サイトは、Markdownベースのドキュメントフレームワーク[Blume](https://useblume.dev)で構築しています。BlumeはAstroとViteで作られています。
このリポジトリに含まれるのは、コンテンツ、設定、少数の手書きAstroページとコンポーネント、News Editor用のCloudflare Pages Functionsです。
フレームワーク自体のコードは含みません。

## ページを編集する

編集方法は2つあります。どちらの方法でも、変更はPull Requestとして提案され、管理者が承認するとサイトに反映されます。
公開サイトへの反映は、毎日午前3時の自動デプロイで行われます。

### ニュース記事を投稿・編集する（News Editor）

<https://mathryukoku.pages.dev/admin/news>

News Editorは、ブラウザのフォームからニュース記事を投稿・編集できるツールです。Markdownやファイル構成を知らなくても記事を追加できます。

- タイトル、日付、概要、本文を入力し、カバー画像（必須）と本文用の画像をアップロードすれば投稿できます。
- 画像は自動的にJPEGへ変換され、縮小されます。iPhoneのHEIC形式の写真は、Safariなど対応するブラウザであればそのまま選べます。
- 投稿するとPull Requestが作られ、プレビューURLで公開前の見た目を確認できます。
- 内容に問題があれば、同じ画面で「修正する」か「この投稿を取り消す」を選べます。「修正する」は同じPRを上書きし、「この投稿を取り消す」はPRを取り消して破棄します。
- 既存のニュース記事もこの画面から修正できます。

利用するには、GitHubアカウントでログインしてください。このリポジトリへの書き込み権限（コラボレーター登録）が必要なので、初めて使う場合は管理者に相談してください。

### その他のページを編集する（GitHubのWeb画面）

ニュース以外のページ（課程紹介、教員紹介など）は、`docs/`以下の`.mdx`ファイルを直接編集します。
パソコンに開発環境がなくても、GitHubのWeb画面だけで編集できます。

手順は[CONTRIBUTING.md](CONTRIBUTING.md)にまとめています。ブランチを作成し、編集してPull Requestを出し、プレビューで確認する流れです。

## ローカル開発

```bash
npm install      # 依存関係をインストール
npm run dev      # 開発サーバー起動（ホットリロード付き、http://localhost:4321）
npm run build    # dist/ に出力をビルド
npm run doctor   # 設定・コンテンツの問題を診断
```

Lintやテストスイートはありません。変更内容は`npm run dev`で実際のページを開いて確認してください。

サイトの配信構成やNews Editorの動作に必要な環境変数は、`.env.example`を参照してください（管理者向け）。
